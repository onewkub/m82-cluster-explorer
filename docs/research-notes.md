# M82 Cluster Explorer

ดับเบิลคลิก `Start Explorer.cmd` เพื่อเปิดเว็บในเบราว์เซอร์ ใช้ Python ที่มีอยู่ในโครงการ M82 และไม่ต้องติดตั้งแพ็กเกจเพิ่ม หากย้ายไปเครื่องอื่นให้ติดตั้ง Python และใช้ `python server.py` เว็บทำงานในเครื่องโดยไม่ต้องใช้อินเทอร์เน็ต

## การใช้งาน

- สลับ DBSCAN 2D / DBSCAN 3D / HDBSCAN ที่ด้านบน
- เลือกกลุ่มจากรายการ ค้นหาหมายเลข หรือคลิกดาวบนแผนที่
- ใช้ขยายกลุ่ม / ทั้งสนาม / ไป DF-E1 ลากเพื่อเลื่อนและเลื่อนล้อเพื่อซูม
- วงทึบคือรัศมี RMS; เปิดวงเส้นประเพื่อดูรัศมีของสมาชิกไกลสุด
- รายละเอียดแสดงจำนวนสมาชิก รัศมี ตำแหน่ง IQR และ CMD
- การสลับวิธีเลือกกลุ่มที่มีสมาชิกทับซ้อนกับกลุ่มเดิมมากที่สุด หากไม่มีกลุ่มทับซ้อนจะเลือกกลุ่มใกล้ DF-E1
- ดาวน์โหลดสมาชิก CSV และภาพ PNG ได้ รวมทั้งคัดลอก URL ซึ่งเก็บวิธีและหมายเลขกลุ่ม
- คำว่า 3D หมายถึงใช้ตำแหน่งสองแกนร่วมกับสี ไม่ใช่ระยะลึกจริง

## ข้อมูล

ใช้ label ที่บันทึกไว้ใน D:\research\m82-bfs-ff ไม่ได้รันอัลกอริทึมใหม่:

| วิธี | ไฟล์ | จำนวนกลุ่ม |
|---|---|---:|
| 2D | m82_dwarf_galaxy_candidates_2d.csv | 510 |
| 3D | m82_clusters_3d_live.csv | 49 |
| HDBSCAN | m82_dwarf_galaxy_candidates_2d_hdbscan.csv | 318 |

ตรวจว่า RA/Dec, MAG1_ACS/MAG2_ACS และประชากรตรงกันทุกแถวทั้ง 408,213 แถวก่อนรวมข้อมูล แผนที่ใช้ TAN ระนาบเดียว รัศมีใช้ระยะฮาเวอร์ไซน์จากศูนย์กลางเฉลี่ย RA/Dec แล้วคูณ 17 pc/arcsec การจัดกลุ่มไม่เปลี่ยนตามการซูมหรือวงรัศมี

ตัวกรองคุณภาพ 391 กลุ่มอิง candidates_quality_screening.csv เดิมในเล่ม ไม่แก้ตัวเลข PCA ที่รอปรับหลังสอบ ชื่อ O-/Y- ใช้ label เดิมของแต่ละวิธี หมายเลขเดียวกันข้ามวิธีไม่ได้หมายถึงสมาชิกเดียวกัน

แผนที่แสดงดาวครบทุกดวงตามตัวกรอง ใน CMD กลุ่มใหญ่มากแสดงตัวอย่างแบบลำดับสูงสุดประมาณ 18,000 จุดเพื่อให้ใช้งานคล่อง โดยบอกไว้ใต้กราฟ จำนวนสมาชิก IQR รัศมี และ CSV ใช้สมาชิกครบ

ขนาดไม่ใช่รัศมีครึ่งแสง และการอยู่ใกล้ DF-E1 ไม่ใช่การยืนยันตัววัตถุ พิกัดอ้างอิง DF-E1 คือ 149.1341°, 69.7126°

## สร้างข้อมูลใหม่

รัน `prepare_data.py` ด้วย Python ของโครงการ (ต้องมี pandas/numpy) แล้ว refresh เว็บ ไฟล์ catalog.json บันทึกชื่อและ SHA-256 ของต้นทาง ไฟล์ bin เป็น little-endian: points Float32 [east,north,RA,Dec,MAG1,MAG2], radec Float64 [RA,Dec], population Uint8 [old=0/young=1], label ทั้งสามวิธี Int16 [noise=-1]

รัศมีตรวจตัวอย่าง Y-1075: 13 สมาชิก, RMS 24.587321 pc, rmax 38.037314 pc, ห่าง DF-E1 5.772542 arcsec, IQR 0.318 mag


## พื้นหลังจาก FITS

เปิด/ปิดภาพ Hubble ได้ใต้แผนที่ และปรับความทึบภาพกับความเข้มจุดดาวแยกกันได้ เลือกแสดงเฉพาะกลุ่มที่เลือกเพื่อดูภาพ M82 ชัดขึ้น ภาพจะติดไปใน PNG ที่บันทึกด้วย

ภาพพื้นหลังสร้างจากไฟล์ `*_f435w_v1_ref.fits` ทั้ง 6 สนามในโฟลเดอร์ file/pos1–pos6 เป็นภาพฟิลเตอร์เดียว F435W แสดงขาวดำ ไม่ใช่ภาพสีประชาสัมพันธ์ รวมภาพด้วย WCS ลง TAN เดียวกับดาวที่ความละเอียด 0.15 arcsec/pixel ปรับภาพด้วย asinh โดยใช้สเกลเดียวกันทุกสนามและเฉลี่ยค่าบริเวณทับซ้อนหลังหารด้วยเวลาเปิดรับแสง ภาพนี้ใช้เพื่อแสดงบริบท ไม่ใช้วัด photometry ใหม่

ไฟล์ผ่าน MultiDrizzle (`DRIZCORR=COMPLETE`) แล้ว แต่ header ยังมี SIP เก่า จึงตัด SIP ออกจาก WCS สำหรับการแสดงภาพเพื่อไม่แก้ distortion ซ้ำ ตรวจเทียบ X/Y แบบ FITS origin=1 กับ RA/Dec ใน catalogue ทุกสนาม โดยค่าคลาดเคลื่อนสูงสุดของตัวอย่างต่ำกว่า 0.025 arcsec บันทึกสถิติและ SHA-256 ไว้ใน dist/data/background.json ข้อนี้เป็นการตรวจความสอดคล้องภายในข้อมูล ไม่ใช่การรับรอง astrometry สัมบูรณ์จากภายนอก

สร้างภาพใหม่ด้วย `prepare_background.py` (numpy, scipy, astropy, Pillow) ไฟล์ FITS ต้นฉบับไม่ถูกแก้ไข


## กรองกลุ่มสมาชิกเกิน 100 ดวง

ตัวเลือก “ซ่อนกลุ่มที่มีสมาชิกเกิน 100 ดวง” เปิดไว้ตั้งแต่เริ่มต้น และกรองทั้งรายการ จุดดาว และการเลือกกลุ่มในทั้งสามวิธี กลุ่ม N=100 ยังแสดงอยู่ ปิดเครื่องหมายถูกเพื่อกลับไปดูทุกกลุ่มได้ ไม่ตัดข้อมูลออกจากไฟล์ต้นทางหรือเปลี่ยน label

หลังกรองเหลือ 2D 499/510 กลุ่ม, 3D 46/49 กลุ่ม และ HDBSCAN 312/318 กลุ่ม หากเลือกประชากรอายุมากใน HDBSCAN จะไม่เหลือกลุ่ม เพราะมีเพียง O-0 ซึ่งเกินเกณฑ์ เว็บจะแสดงว่าไม่มีกลุ่มที่เลือกและปิดปุ่มส่งออกจนกว่าจะเปลี่ยนตัวกรอง

การสลับวิธีจะจับสมาชิกทับซ้อนเฉพาะในกลุ่มที่ไม่ถูกซ่อน หากไม่มีคู่ที่เลือกได้จะเลือกกลุ่มใกล้ DF-E1 ที่ผ่านตัวกรอง จำนวนทั้งหมดในคำอธิบายวิธียังคงเป็นจำนวนกลุ่มก่อนกรอง ส่วนจำนวนรายการคือผลหลังกรอง
